## ✨ A few things I've built

### 🌎 Geospatial & Computer Vision
Graduate coursework from **CS 513: Geospatial Vision & Visualization** at Illinois Institute of Technology, co-developed with Christopher Dharma.

- **Imagery Retrieval** — Built a Python pipeline that converts latitude/longitude bounds into map tiles, retrieves geospatial imagery, and mosaics it into a single cropped image.
- **Probe Data Analysis** — Implemented Python map-matching and network analysis to associate GPS probe points with road links and estimate road slope.
- **Lane Marking Detection** — Developed a Python point-cloud processing pipeline using spatial filtering, coordinate transformations, OPTICS clustering, and computer vision to identify road lane markings.
- **Smear Detection** — Used Python and OpenCV to process large image sets and automatically detect persistent camera smears and image artifacts.
