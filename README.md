### ✍️ [Wordsmith — Notion Writing Pulse](https://github.com/gmarnold/wordsmith-notion-writing-pulse)
I built Wordsmith because I wanted to write and organize novels in Notion without giving up the word-count and progress tools I liked in dedicated writing software.

Wordsmith connects to a Notion writing database, calculates page and manuscript word counts, tracks progress over time, supports writing goals, and can surface the results back inside Notion. I'm continuing to develop it toward an always-on integration that writers can configure once and then use without leaving their workspace.

**React · TypeScript · Node.js · PostgreSQL · Notion API · Webhooks**

### 👗 [Virtual Wardrobe](https://github.com/gmarnold/virtual-wardrobe)
A full-stack wardrobe application inspired by a problem I actually have: keeping track of my closet, planning outfits, and experimenting with combinations without pulling everything off a hanger.

The first phase establishes a real end-to-end application with a React/TypeScript frontend, ASP.NET Core API, and PostgreSQL database. The longer-term plan is to add a Unity dress-up client that consumes the same API and turns the wardrobe into a small styling game.

**React · TypeScript · C# · ASP.NET Core · PostgreSQL · Docker**

*Unity dress-up client planned for a later phase.*

## 🛠️ Earlier projects

### 🌎 Geospatial & Computer Vision
Graduate work from **CS 513: Geospatial Vision & Visualization** at Illinois Institute of Technology, co-developed with Christopher Dharma.

- **Imagery Retrieval** — Built a Python pipeline that converts latitude/longitude bounds into map tiles, retrieves geospatial imagery, and mosaics it into a single cropped image.
- **Probe Data Analysis** — Implemented map-matching and network analysis to associate GPS probe points with road links and estimate road slope.
- **Lane Marking Detection** — Developed a point-cloud processing pipeline using spatial filtering, coordinate transformations, OPTICS clustering, and computer vision to identify road lane markings.
- **Smear Detection** — Used Python and OpenCV to process large image sets and detect persistent camera smears and image artifacts.
